# 🎌 日本語ノート｜12週旅行・日常・N2 學習計畫

專為「上班族、下班後自學」設計的日語學習網站。從「50音尚未完全學會」出發，用 12 週的時間逐步練到能應付**旅行、日常對話**，並開始接觸 **N2** 的詞彙與文法。純靜態網頁，沒有任何後端或建置步驟，可以直接部署到 GitHub Pages。

## 📦 網站內容

- **`index.html`** — 首頁總覽，顯示學習進度與使用方式
- **`plan.html`** — 12 週學習計畫，每週有明確主題、每日時間分配、目標、練習任務與里程碑
- **`vocab.html`** — 200 個核心詞彙，依旅行／日常／N2 場景分類，可搜尋、篩選、打勾記錄學會的單字
- **`grammar.html`** — 12 個核心文法課程，每課包含繁體中文說明、3 個例句、1 個常見錯誤提醒
- **`data/`** — 三份資料檔（`plan.js`／`vocab.js`／`grammar.js`），之後想調整內容或新增單字，只要改這幾個檔案就好，不用碰版面
- **`css/style.css`** — 網站樣式（和紙感配色＋明朝體標題）
- **`js/app.js`** — 頁面互動邏輯（篩選、搜尋、進度儲存）

## 🚀 部署到 GitHub Pages

1. 在 GitHub 建立一個新的 repository（例如 `nihongo-12week`）
2. 把這個資料夾裡的所有檔案上傳（保留原本的資料夾結構，`css/`、`js/`、`data/` 都要一起上傳）
3. 到 repository 的 **Settings → Pages**
4. 在 **Branch** 選擇 `main`（或妳的預設分支），資料夾選 `/ (root)`，儲存
5. 等 1〜2 分鐘，網站就會出現在 `https://<你的帳號>.github.io/nihongo-12week/`

> 💡 妳的 skill-map 網站也是用同樣的方式上線的，這次的結構會更眼熟。

## 💾 進度儲存說明

學習進度（已完成的週次、已學會的單字）是存在**瀏覽器的 localStorage**，只存在你使用的那一台裝置、那個瀏覽器上：

- 不會上傳到任何伺服器，完全離線運作
- 清除瀏覽器資料或換裝置，進度就會重置
- 如果之後想加上「跨裝置同步」，可以考慮串接一個免費的雲端資料庫（例如 Supabase），但目前的版本刻意保持單純、零設定

## ✏️ 之後想自己調整內容

- 想新增或修改單字：打開 `data/vocab.js`，依照現有的格式（`jp`／`reading`／`zh`／`ex`／`exZh`）新增物件即可，`id` 記得不要重複
- 想調整某一週的計畫：打開 `data/plan.js` 找到對應的 `week` 物件修改
- 想新增文法課程：打開 `data/grammar.js`，格式包含 `explanation`（說明）、`examples`（3 個例句）、`mistake`（常見錯誤）

## 🌱 誠實的小提醒

12 週能扎實打好 50音、N5〜N4 的基礎，並開始接觸 N3 文法與 N2 詞彙、閱讀，但要真正**應考 N2** 通常需要更長的累積。這份計畫的目標是讓妳穩定前進、不半途而廢——走完 12 週之後，妳會清楚知道自己該往哪個方向繼續加強。頑張ってください 💪
